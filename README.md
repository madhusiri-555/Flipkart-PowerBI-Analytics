# Flipkart E-Commerce Product Analytics Dashboard

## Project Overview
This project is an interactive Flipkart E-Commerce Product Analytics Dashboard developed using Microsoft Power BI.

The dashboard analyzes product categories, brands, pricing, discounts, ratings, and customer reviews to generate useful business insights.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Microsoft Excel / CSV
- Data Visualization

## Data Cleaning
- Removed duplicate records
- Checked missing values
- Corrected data types
- Checked data errors
- Prepared data for analysis

## Key Analysis
- Total Products
- Total Brands
- Average Selling Price
- Average Discount
- Average Rating
- Total Reviews
- Category Analysis
- Brand Analysis
- Price Analysis
- Rating Analysis
- Review Analysis

## Dashboard Pages

### 1. Executive Overview
Provides overall KPIs and high-level product, brand, pricing, rating and review analysis.

### 2. Product & Category Analysis
Provides detailed analysis of categories, brands, prices, discounts, ratings and reviews.

### 3. Insights & Project Guide
Contains project information, key business insights, measures used and dashboard instructions.

## Key Business Insights
- Around 3K products are analyzed across 212 brands.
- Laptops have the highest average selling price among the analyzed categories.
- Smartphones have one of the highest average discounts.
- Samsung has the highest number of products among the top brands.
- The overall average product rating is approximately 4.2.
- Mobiles have the highest review volume.

## Conclusion
This project demonstrates how Power BI can be used to clean, analyze and visualize e-commerce data and convert raw data into meaningful business insights.
